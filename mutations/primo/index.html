How to breed a Primo Pal

A variant is bred like any other Pal: pick it as the target and the calculator returns the pairs that produce it. The pairs belong to the variant, not to the base Pal. Every Primo form comes from the same small set — 2 pairs each — which is what a fixed recipe looks like in the data. Open any Pal above to see them listed cheapest first.
