Palworld Variant Pals — All 85 Mutations

Palworld 1.0 has 85 variant forms across 12 families. Each one is its own Paldeck entry with its own element, stats and breeding pairs — a Cryst form is not an Ice-coated version of the base Pal, it is a different Pal that you breed for directly.

Variant Pals85 Families12 Share of the Paldeck28%

What a variant actually is

There is no mutation step and no item that converts a Pal. The variant sits in the Paldeck next to its base form, usually with a different element and a different rarity, and it is produced by its own set of parent pairs. How reachable they are varies enormously: Wumpo Botan comes from 576 pairs, while 5 variants — Gumoss, Wixen Noct, Katress Ignis, Blazamut Ryu, Bellanoir Libero — breed only from themselves, so the first one has to be caught in the wild.

Because the pairs belong to the variant rather than to the base Pal, looking up "Jormuntide" tells you nothing about Jormuntide Ignis. Open the variant itself.
