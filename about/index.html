About PalLineage

Last updated: August 15, 2026

PalLineage is a free breeding calculator for Palworld. It answers the two questions every breeding project starts with: what do these two Pals produce, and what do I need to pair to get the Pal I want. There is no account, no download, and no paywall.

Where the data comes from

Breeding combinations, stats and passives are derived from the Palworld v1.0 game data tables, by way of the open-source Pal Calc project (MIT licensed), which generates its dataset directly from the game files. Element types come from the Palworld Helper dataset.

The two sources are joined on each Pal’s internal codename, and the build fails unless their work suitability values agree for all 299 Pals — two independent datasets confirming each other is what makes the numbers here trustworthy. The current build covers:

  • 299 Pals in the v1.0 Paldeck, including 85 variant forms
  • 44,849 parent pairs and the child each one produces
  • The two pairings whose outcome depends on parent gender
  • Element types and all 12 work suitabilities, on the rebalanced v1.0 scale

Nothing here is hand-typed or copied from another calculator, which is why the numbers hold up: a combination shown in the tool is the same combination the game uses.

How it stays current

The dataset is regenerated from the upstream source and re-published after each game patch. The date at the top of this page and in the site header reflects the last data refresh, not just an edit to the text.

Corrections

If a combination looks wrong, please tell us with the two parents and what actually hatched. Reports get checked against the game data and fixed in the next build.
