Palworld Frostallion Breeding Combos

Frostallion cannot be bred from two different Pals. The only pair that produces it is Frostallion with another Frostallion, so the first one has to be caught in the wild — after that it breeds true.

Paldex#200 Rarity20 ElementIce Parent pairs1 Can produce73 Pals

Work suitabilityCooling 7

How to breed Frostallion

Pair the two Pals in a Breeding Farm with cake in the feed box. Parent order never matters — Frostallion + Frostallion and Frostallion + Frostallion both hatch Frostallion.
