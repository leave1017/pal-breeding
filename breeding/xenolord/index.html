Palworld Xenolord Breeding Combos

Xenolord cannot be bred from two different Pals. The only pair that produces it is Xenolord with another Xenolord, so the first one has to be caught in the wild — after that it breeds true.

Paldex#196 Rarity8 ElementDarkDragon Parent pairs1 Can produce82 Pals

Work suitabilityGathering 2

Always hatches withInvaderOtherworldly Cells

How to breed Xenolord

Pair the two Pals in a Breeding Farm with cake in the feed box. Parent order never matters — Xenolord + Xenolord and Xenolord + Xenolord both hatch Xenolord.
