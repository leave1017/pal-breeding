Palworld Panthalus Breeding Combos

Panthalus cannot be bred from two different Pals. The only pair that produces it is Panthalus with another Panthalus, so the first one has to be caught in the wild — after that it breeds true.

Paldex#203 Rarity10 ElementWater Parent pairs1 Can produce71 Pals

How to breed Panthalus

Pair the two Pals in a Breeding Farm with cake in the feed box. Parent order never matters — Panthalus + Panthalus and Panthalus + Panthalus both hatch Panthalus.
