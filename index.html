How breeding works in Palworld 1.0

Breeding in Palworld pairs a male and a female Pal at a Breeding Farm. Give them cake, wait for the egg, and the child is decided by a fixed table rather than chance — which is why a calculator works at all. Parent order does not matter: Orserk + Vixy and Vixy + Orserk hatch the same Pal.

What changed in 1.0

  • New Pals added to the Paldeck brought roughly 180 new or shifted parent combinations.
  • Mutation variants entered the breeding table, so some pairs can now roll an alternate form.
  • Passive skill inheritance was rebalanced, which changes how you chain a four-passive breeding project.

Every table on this site is built from Palworld v1.0 game data and re-checked after each patch, so you are not working from pre-1.0 numbers that quietly stopped being true.

Using the calculator

Start from whichever end you know. If you want a specific Pal, open Find Parents and pick it — you get every pair that produces it. If you already have two Pals sitting in the ranch, use Find Child. If you are somewhere in between, Shortest Path works out the fewest eggs from what you own to what you want.

FAQ

Is this Palworld breeding calculator updated for 1.0?

Yes. All combinations, mutations and passive data come from Palworld v1.0 game files, and the update date in the header reflects the last data refresh.

Does the order of the two parent Pals matter?

No. The breeding table is order-independent, so A + B and B + A always hatch the same child. You only need to check a pair once.

How do I get a specific Pal with the fewest breeding steps?

Use the Shortest Path tool. Enter a Pal you already own and the one you want, and it searches the whole breeding graph for the chain with the fewest eggs.

Can I breed for specific passive skills?

Yes. The Passives tab ranks parent pairs by how likely they are to pass the passives you select. Both parents contribute, so pairing two carriers gives the best odds.

Is the calculator free?

Free, no account, no download. It runs in any browser on desktop and mobile.
