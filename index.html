How Breeding Works in Palworld 1.0

Breeding in Palworld pairs a male and a female Pal at a Breeding Farm. Feed them cake, wait for the egg, and the child is decided by a fixed table rather than chance — which is why a breeding calculator works at all. Parent order does not matter: Grizzbolt + Relaxaurus and Relaxaurus + Grizzbolt both hatch Reptyro.

What Changed in 1.0

  • The v1.0 Paldeck holds 299 Pals, 85 of them variant forms, and every variant is obtainable through breeding.
  • Some Pals can only be bred from themselves — Frostallion, Necromus, Selyne and Xenolord each have exactly one valid pair.
  • Passive skill inheritance was rebalanced, which changes how you chain a four-passive breeding project — the passives guaranteed by species are the reliable starting points.
  • Cake cost is unchanged, but longer chains now cost more overall — one more reason to check the shortest path before you start.

Every table on this site is built from Palworld v1.0 game data and re-checked after each patch, so you are not working from pre-1.0 numbers that quietly stopped being true.

Palworld Breeding Calculator FAQ

What is a Palworld breeding calculator?

It is a lookup tool for the game's breeding table. Palworld decides a child from its two parents by a fixed rule, not by chance, so the result of any pair can be worked out in advance. PalLineage holds all 44,849 parent pairs across the 299 Pals in the v1.0 Paldeck, and it is free to use with no account.

Is this Palworld breeding calculator updated for 1.0?

Yes. Every combination, variant and passive on this page is generated from the Palworld v1.0 game files, and the dataset is rebuilt from source after each patch.

How do I use the Palworld breeding calculator?

Pick the end you already know. Know the Pal you want? Use Find Parents. Know the two Pals in your ranch? Use Find Child. Somewhere in between, Shortest Path plans the route. There is a step-by-step walkthrough further up this page.

Does the order of the two parent Pals matter?

No. The breeding table is order-independent, so A + B and B + A always hatch the same child. You only need to check a pair once.

How do I get a specific Pal with the fewest breeding steps?

Use the Shortest Path tool. Enter a Pal you already own and the one you want, and it searches the whole breeding graph for the chain with the fewest eggs.

Can I breed for specific passive skills?

Yes. The Passives tab ranks parent pairs by how likely they are to pass the passives you select. Both parents contribute, so pairing two carriers gives the best odds — the list of passives guaranteed by species is where a project usually starts.

Is there a Palworld breeding calculator app?

There is no separate download. This is a web app — open it in any mobile browser and add it to your home screen, and it behaves like an app while staying up to date with every patch.

What are mutated eggs in Palworld 1.0?

Variant forms — Lux, Cryst, Ignis, Terra, Noct — are separate Pals in the Paldeck with their own breeding pairs. All 85 of them can be bred; the full variant list covers every family, and the Mutations tab gives the exact pairs.

Which Pals are worth breeding in Palworld 1.0?

It depends on what you are short of, so the calculator answers it per-Pal rather than handing you a ranking. Two things are worth knowing before you plan: some Pals are reachable from hundreds of pairs — Anubis has 234 — while the four top-tier ones (Frostallion, Necromus, Selyne, Xenolord) have exactly one valid pair each, themselves. Check the target's page first; it tells you immediately whether the Pal is a short hop or a long project.

The calculator is not showing a result — what went wrong?

Almost always it is a pair with no offspring in the table, or a target that can only come from itself. Both cases are shown explicitly rather than left blank. If the page itself looks stuck, reload once — the tool loads its dataset in the background and a dropped connection leaves the grid empty. If a result looks wrong against the game, tell us and we will re-check it against the files.

Is the calculator free?

Free, no account, no download, no ads in the tool. It runs in any browser on desktop and mobile.
