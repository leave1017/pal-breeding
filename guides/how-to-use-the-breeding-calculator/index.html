How to Use the Palworld Breeding Calculator

Six modes, one dataset. The one you want depends on which end of the problem you already know.

Start from what you already have

  • You own two Pals and want to know what they make → Parents → Child.
  • You want a specific Pal → Target → Parents. Pairs are sorted cheapest first, by the combined rarity of the two parents, so the practical answer is at the top rather than buried.
  • You have one good Pal and want to see its options → One Parent → All: every partner and what each one produces.
  • You are several generations away → Shortest Route walks the whole breeding graph and returns the chain with the fewest eggs.

Two modes worth knowing about

Passives lists the Pals that always hatch with a passive attached. Breeding from a carrier is the cheapest way into a four-passive project, because the skill is guaranteed on the egg instead of rerolled.

Mutations covers the 85 variant forms — Lux, Cryst, Ignis, Terra, Noct. All of them are breedable, but through fixed recipes rather than the usual arithmetic, so they need looking up.

Finding a Pal quickly

The search box takes more than exact names. Type part of a name, a Paldex number, an element ("fire") or a job ("mining"), and half-remembered spellings still work — "anb" finds Anubis. The element, work and rarity dropdowns stack on top of the search, so "Dragon" plus "Kindling" narrows 299 Pals to four.

Practical notes

  • A Breeding Farm needs a male and a female of any species, plus cake in the feed box. One cake per egg.
  • Parent order never changes the child, so a pair only needs checking once.
  • Some Pals — Frostallion, Necromus, Selyne, Xenolord among them — have exactly one valid pair: themselves. The first one has to be caught.
  • Every number here is generated from the v1.0 game files and rebuilt after each patch. If a result does not match your game, tell us.
